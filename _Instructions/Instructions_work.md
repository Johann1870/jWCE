# New Work computer set up checklist

## Old Computer
1. Make sure Documents is backed up to OneDrive
2. Make sure git repositories have been updated and are pushed to remote
3. Make sure Dropbox is up to date and synced
4. Back up script folder
5. Back up configs for
	a. Conemu
	b. Qdir
	c. Pulsar
	d. Notepad++
	e. Excel
	f. Word
	g. Outlook
	h. Visual Studio Code (sign in with Github)
	i. Postman
	j. Firefox (back up bookmarks and settings)
	k. ShareX
	l. XMBC settings
